Agent Browser — Early Tester Feedback

Current honest scope: Agent Browser is in early public-first testing for one narrow use case: mobile approval / oversight for browser-agent workflows.

The live public path right now is Android testing. If you try it and hit something confusing, brittle, or broken, use the feedback form below.

What feedback is most useful

Setup friction

Anything confusing about joining the Android test, installing, or getting to first use.

Approval reliability

Did the pending approval appear when expected, and did approve/deny behave correctly?

Trust / clarity

Did the approval step feel understandable and safe enough to use in a real workflow?

Reproducible bugs

Device, Android version, exact steps, and the first confusing or broken moment.

First workflow to try

  1. Join the Android test build from Google Play.
  2. Open the app on your Android device.
  3. Use a safe workflow where a human approval step should appear.
  4. Check whether the request appears clearly in the app.
  5. Approve it if the request looks correct.
  6. Report whether the browser workflow resumed as expected.
